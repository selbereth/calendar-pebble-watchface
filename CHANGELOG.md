# Changelog

## 1.0.0

- Initial release.
- Shows the current time and your next 3 upcoming calendar events, read
  directly from the Pebble app's built-in calendar sync (no manual setup
  or ICS URL needed).
- Requires the Pebble app's experimental plugin API (Settings → Debug →
  Show debug options → "Use experimental plugins") until it's out of
  experimental status.
